Oxide — Local-First Autonomous AI Coding Agent

A lightning-fast desktop command center built with Tauri v2, Rust, and React 18 / TypeScript. Designed to execute autonomous software engineering loops entirely offline with local Ollama models (qwen2.5-coder / gemma2), bounded terminal sandboxing, automatic stderr self-correction, and one-click VS Code integration.

Tauri v2 + Rust Backend Ollama Local Streaming (localhost:11434) Cloud Hybrid Fallback (Claude / OpenAI) Sandboxed Terminal & Auto Git Commits One-Click Open in VS Code

1. How to Open & Run Oxide

Choose any of the launch modes below depending on whether you want a one-click launcher, a development desktop window, or a standalone native .exe installer.

Step 1: Prerequisites

  • Node.js (v18+): nodejs.org
  • Rust Toolchain: rustup.rs (plus MSVC C++ build tools on Windows)
  • Ollama: ollama.com running on localhost:11434
ollama pull qwen2.5-coder:latest
ollama serve

Option A: One-Click Windows Launcher

Double-click start-oxide.bat in the repository root or run it from PowerShell: 

.\start-oxide.bat

Automatically installs missing npm packages and launches the native Tauri desktop window (or falls back to the browser preview at http://localhost:1420 if Rust is not yet installed).

Option B: Launch Desktop App (Dev Mode)

Run from the repository root to compile the Rust core and open the native desktop window with hot-reload: 

npm install
npm start
# (or: npm run tauri dev)

Option C: Build Standalone Native Installer

Compile a tiny, self-contained native binary (.exe / .msi / .dmg): 

npm run desktop:build

Output binary: src-tauri/target/release/oxide-agent.exe

2. Using the Command Center

  1. Bind Target Workspace Sandbox: Enter your local project path in the top bar (e.g., C:\projects\my-app) and click Bind Sandbox. Oxide canonicalizes the path and jails all file/process operations to that folder.
  2. Select Inference Provider: Pick Local: Ollama / qwen2.5-coder or Local: Ollama / gemma2 in the header selector, or switch to Anthropic Claude / OpenAI GPT-4o when API keys are set in your environment.
  3. Open in VS Code: Click the sticky blue Open in VS Code button in the top-right header at any time to launch Visual Studio Code directly in the active workspace (code -- <canonical_path>).
  4. Dispatch Autonomous Tasks: Enter a coding goal in the prompt composer and click Dispatch Agent. Watch live streaming tokens on the left and step-by-step workflow status cards, stderr self-correction loops, and automated Git milestone commits on the right.

4. Defense-in-Depth Terminal Security Boundaries

Security Layer Threat Mitigated Rust Implementation
1. Direct OS Argv Spawning Shell injection via &&, ||, ;, |, `, $() WorkspaceSandbox::sanitize_command rejects shell chaining tokens and spawns binaries directly via tokio::process::Command without sh -c or cmd /C.
2. Canonical Workspace Jail ../ path traversal & symlink escapes dunce::canonicalize resolves real paths and enforces target.starts_with(&canonical_root).
3. System Root Refusal Binding /, C:\, C:\Windows, /etc reject_system_root refuses shallow root directories and OS system trees.
4. Binary Allowlist Policy Privilege escalation (sudo, rm, powershell, curl) CommandPolicy permits only approved developer toolchains (cargo, npm, git, pytest, tsc, etc.).
5. Credential Scrubbing Prompt-injected scripts leaking API keys BoundedTerminalExecutor removes OPENAI_API_KEY, ANTHROPIC_API_KEY, GITHUB_TOKEN, and SSH_AUTH_SOCK from child processes.
6. Timeouts & Output Caps Hung interactive prompts & memory exhaustion Enforces 60s execution timeout, kill_on_drop(true), CI=true, and 128 KiB output stream truncation.
