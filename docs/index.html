1. How to Open & Start Oxide

Option A: Standalone Windows Installer / .exe (Easiest)

GitHub Actions automatically compiles and publishes the Windows installer and portable executable on every push to main:

  1. Open GitHub Releases.
  2. Download Oxide_0.1.0_x64-setup.exe (Windows Installer) or Oxide-Portable.exe (Single-File Portable Executable).
  3. Double-click to launch Oxide Studio!

Option B: Double-Click start-oxide.bat

From a local clone of the repository, double-click start-oxide.bat in File Explorer: 

.\start-oxide.bat

Runs Oxide-Portable.exe if present, or opens a standalone desktop GUI window (--app=http://localhost:1420) with full local system capabilities!

2. Lead Architect + Subagents & PC Hardware Governor

🧠 Hierarchical Subagent Delegation

Run one large model (e.g. deepseek-r1 or qwen2.5-coder:14b) as the Lead Architect AI for complex planning, and delegate subtasks to faster, lighter Subagents (coder_subagent, research_subagent, tester_subagent).

⚙ Task-to-Model Routing Matrix

Click ⚙ Subagents & Models in the top bar to choose which AI model runs each specific task role—or click ✨ Auto-Configure for My PC to automatically pick the best models for your hardware.

🖥 PC Hardware Concurrency Limiter

Oxide continuously checks your PC's Free RAM / Total RAM (GB), CPU Cores & Load %, and GPU VRAM. It enforces a hard semaphore limit so too many subagents can never overload your PC, and auto-throttles to 1 sequential worker if RAM exceeds 85%.

🤖 Live Subagent Worker Pool

Watch every active or queued Subagent in the right-hand panel with its assigned role, model tag, status (QUEUED, RUNNING, COMPLETED), live thought (💭), and result preview.

3. Live AI Thinking & Full Autonomous Tool Suite

  • 🧠 Live AI Thinking Panel: Streams real-time <think>...</think> reasoning and numbered task checklists at the top of the center workspace.
  • 📁 Built-in File Explorer & Code Editor: Browse folders, view/edit/save files, create new files, move/rename files, or delete files directly in the GUI.
  • 🛠 Terminal & Self-Correction Loop: Runs bounded commands and automatically feeds non-zero exit codes (stderr) back to the agent for autonomous repair.
  • 🌿 One-Click Git & VS Code Controls: Pull, Commit, Push, and pop open Visual Studio Code directly from the top bar.

4. Updating Oxide from GitHub with One Click

Click the ↻ Update button in the top-right header of the GUI to check https://github.com/Hanzkii/Oxide for new releases or commits and install updates with a single click.
