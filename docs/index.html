Oxide Studio — Antigravity-Style Local AI Agent GUI

A full-featured desktop GUI for autonomous software development. Watch what the AI is thinking in real time (<think>... & live step plans), switch local Ollama models or settings visually, browse/edit/move files in the sidebar, execute terminal commands with automatic self-correction, push/pull with Git, and update the program directly from GitHub with one click.

1. How to Open & Start Oxide (Zero-Setup Executable or One-Click Script)

Option A: Download Standalone Installer / .exe (Easiest)

Every push to main automatically builds and publishes the ready-to-run Windows installer and portable executable on GitHub Releases:

  1. Go to GitHub Releases.
  2. Download Oxide_0.1.0_x64-setup.exe (installer) or Oxide-Portable.exe (no install needed).
  3. Double-click to open Oxide Studio!

Option B: Double-Click start-oxide.bat

If you cloned the repository, simply double-click start-oxide.bat in File Explorer: 

.\start-oxide.bat

If Oxide-Portable.exe is present, it runs it directly. Otherwise, it automatically opens a standalone desktop GUI window (--app=http://localhost:1420) with the full local system bridge enabled!

2. GUI Overview & Live AI Thinking Display

🧠 Live AI Thinking & Step Checklist

At the top of the center pane, the purple AI Live Thinking & Current Reasoning box streams the model's internal thought process (<think>...</think>) and numbered task plan in real time so you always see what the AI is analyzing and doing right now.

⚙ Visual Model & Settings Manager

Click ⚙ Models & Settings in the top bar to switch between locally installed Ollama models (auto-detected from localhost:11434), enter custom model tags, adjust sampling temperature, or select Anthropic Claude / OpenAI.

📁 Built-In File Explorer & Code Editor

The left sidebar lets you browse workspace directories, click any file to view/edit/save its code, create new files (+ File), rename/move files, or delete files—all visually inside the GUI.

🌿 One-Click Git Pull, Commit & Push

Use the top bar buttons (⬇ Git Pull, ✔ Commit, ⬆ Git Push, and Open in VS Code) or ask the autonomous agent to handle Git operations for you.

3. Autonomous Agent Tool Suite (Antigravity-Grade)

  • list_dir & search_files — Explores directories and searches code across the entire workspace.
  • read_file, write_file, edit_file — Reads files, creates new files, and performs surgical target/replacement code edits.
  • move_file & delete_file — Moves, renames, and cleans up files or directories inside the workspace sandbox.
  • run_command — Runs terminal commands (cargo, npm, pytest, git) and automatically self-corrects when stderr or a non-zero exit code occurs.
  • git_action — Runs pull, push, commit, diff, and status autonomously.
  • open_in_vscode — Pops open modified files or the workspace in Visual Studio Code.

4. Updating Oxide from GitHub with One Click

Click the ↻ Update button in the top-right corner of the GUI at any time:

  • Oxide checks https://github.com/Hanzkii/Oxide for the latest release and commit SHA on main.
  • If a new version is available, the button highlights green (↻ Update Available!).
  • Click Pull & Install Latest Update inside the modal to automatically download & launch the latest GitHub Release installer (or pull the latest commits from origin/main).
