01 // HOW TO OPEN OXIDE
A. Windows Installer (.exe)

Download the latest Oxide-Setup.exe or Oxide-Portable.exe from GitHub Releases and launch Oxide Studio. Use the in-app ↻ Update button to pull future updates with one click.

B. Local Repository Clone

Clone https://github.com/Hanzkii/Oxide.git and double-click start-oxide.bat (or run npm run dev) to launch the studio immediately.

02 // SYSTEM ARCHITECTURE
1-Click AI Model Hub
Built-in Ollama & HuggingFace GGUF store that auto-detects your PC RAM/VRAM and filters models by Coding, Uncensored/Abliterated, Reasoning, and Fast Subagents.
Lead Architect + Subagents
Route complex planning to a large model (deepseek-r1 / qwen2.5-coder:14b) and delegate coding, search, and test subtasks to fast lightweight Subagents.
PC Hardware Governor
Monitors live CPU load, free System RAM, and GPU VRAM to cap concurrent Subagent workers and prevent machine overload.
Live Reasoning Stream
Real-time <think>...</think> inspection panel and step-by-step task checklist visible directly in the center GUI.
MCP Protocol Hub
JSON-RPC 2.0 client for Builtin, Stdio (npx / uvx), and HTTP Model Context Protocol servers with live tools/list discovery.
Workspace & Git Engine
Built-in file explorer/editor (create, edit, move, delete), sandboxed terminal with automatic stderr self-correction, Git pull/commit/push, and one-click Open in VS Code.
