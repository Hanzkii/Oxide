03 // AUTONOMOUS ARCHITECTURE & SUBSYSTEMS

Built for Full-Stack Autonomous Engineering

Every subsystem in Oxide Studio is engineered in Rust + TypeScript to give local AI models the same capabilities as cloud-hosted autonomous coding agents.

🧠

Hierarchical Lead AI + Fast Subagents

Assign a large reasoning model as your Lead Architect to plan tasks and delegate file searches, code edits, and test runs to parallel Coder, Research, and Tester Subagents running faster 1.5B–7B models.

🛡️

PC Hardware Resource Governor

Continuously monitors live CPU load, free System RAM, and GPU VRAM via sysinfo and nvidia-smi. Enforces a strict hardware semaphore so subagents never freeze or overload your machine.

🔌

Model Context Protocol (MCP) Hub

Full JSON-RPC 2.0 client supporting builtin knowledge graphs, stdio servers (npx, uvx, python), and http endpoints with 1-click tools/list discovery.

📁

Multi-Project Tree & Native Folder Picker

Click 📁+ to open any directory using the native Windows folder dialog. Switch between projects and saved conversations effortlessly with automatic disk persistence.

🔒

Silent Execution & Path Sandbox

All background tools (git, ollama, cargo, npm) run inside a canonical path sandbox with Win32 CREATE_NO_WINDOW so sketchy terminal windows never pop up.

↻

1-Click GitHub Self-Updater

Checks Hanzkii/Oxide for new releases or commits on main and installs updates silently in the background with a single click.

04 // QUICK START GUIDE

How to Install & Open Oxide Studio

A. Standalone Windows Installer (`.exe`)

1. Visit GitHub Releases and download Oxide_0.1.0_x64-setup.exe or Oxide-Portable.exe.
2. Launch Oxide Studio.
3. Open ⬇ AI Model Hub (1-Click) in the left sidebar to install your preferred Coding or Uncensored AI model, and click ↻ Update anytime to pull new releases.

B. Local Repository Clone (`start-oxide.bat`)

1. Clone the repository:
git clone https://github.com/Hanzkii/Oxide.git
2. Double-click start-oxide.bat (or run npm install && npm run dev) to launch the studio immediately.
